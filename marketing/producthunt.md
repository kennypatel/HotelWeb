## Description
stripe-launch is a Claude Code skill that automatically adds complete Stripe payment infrastructure to any web project.

Run `/stripe-launch` and it detects your framework (Next.js, Django, Rails, Laravel, Go, Flask, Express), installs the right Stripe SDK, and generates:

- **Checkout endpoint** — one-time payments or subscriptions
- **Webhook handler** — with proper signature verification
- **Customer portal** — for subscription management
- **React checkout button** — drop-in component with TypeScript support
- **Tests** — mocked Stripe calls, covering happy path and errors
- **STRIPE_SETUP.md** — step-by-step go-live guide

Everything is committed to your repo. What normally takes 6-10 hours takes 5 minutes.
